# BookStore – Buổi 9

Thay đổi so với Buổi 8: không cần cài thêm thư viện.

## Chạy
```bash
npm run api          # Terminal 1  → http://localhost:3000
npx expo start -c    # Terminal 2  (-c để Expo nhận app.json mới)
npx tsc --noEmit
```
Chép **App.tsx, app.json, assets/, db.json, src/, TraLoi.md** đè vào project.
Tài khoản demo: demo@bookstore.vn / 123456 (có sẵn 3 đơn, 4 thông báo).
